# Sample credits

Both sets are redistributed here under the Creative Commons Attribution 3.0
licence (https://creativecommons.org/licenses/by/3.0/), which permits copying
and redistribution with attribution. The files are unmodified copies of the
MP3 encodings hosted in the Tone.js audio collection
(https://github.com/Tonejs/audio); the guitar files are renamed to the note
each one sounds.

## `piano/` — Salamander Grand Piano

- Author: Alexander Holm
- Instrument: Yamaha C5 grand piano
- Licence: CC BY 3.0 — stated in the set's own README
  (https://github.com/Tonejs/audio/blob/master/salamander/README)
- Source of these files: https://github.com/Tonejs/audio/tree/master/salamander
- What is here: one note every minor third, C1 to A7 (28 files, `Ds` = D♯,
  `Fs` = F♯). Notes in between are made by changing the playback speed.

## `guitar/` — OLPC / Berklee Sound Library guitar strings

- Author: Berklee College of Music, contributed to the One Laptop per Child
  sound sample library (http://wiki.laptop.org/go/Sound_samples)
- Licence: CC BY 3.0 — stated in the collection's README
  (https://github.com/Tonejs/audio/blob/master/berklee/README.md)
- Source of these files: https://github.com/Tonejs/audio/tree/master/berklee
  (`guitar_LowEstring1`, `guitar_Astring`, `guitar_Dstring`, `guitar_Gstring`,
  `guitar_Bstring`, `guitar_highEstring`)
- What is here: the six open strings, E2 A2 D3 G3 B3 E4. Fretted notes are
  made by changing the playback speed of the nearest open string below.
